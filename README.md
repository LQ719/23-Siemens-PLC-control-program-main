# 2023 年西门子杯逻辑算法赛项｜六部十层电梯群控系统

> **2023 年西门子杯中国智能挑战赛 · 逻辑算法赛项 · 全国决赛一等奖**

## 项目简介

本项目是 **2023 年西门子杯中国智能挑战赛逻辑算法赛项**的参赛作品，并在**全国决赛中获得一等奖**。

项目以 **西门子 S7-1200 PLC** 为控制平台，使用 **TIA Portal V18（博途）** 开发，采用 **SCL（Structured Control Language）** 语言实现 **6 部电梯、10 层楼**的群控系统。系统涵盖电梯群控调度、楼层呼叫响应、运行控制、安全保护以及 HMI 人机界面等功能。

本仓库提供决赛项目程序及相关配置文件，便于查阅项目实现思路和进行学习交流。

## 主要功能

- **电梯群控调度**：对 6 部电梯进行协同调度，兼顾外呼响应时间与运行能耗。
- **楼层呼叫处理**：支持轿厢内部选层，以及厅外上行、下行呼叫。
- **运行方向与路径判断**：根据目标楼层队列判断电梯运行方向，并规划运行路径。
- **到站与门控逻辑**：实现楼层到达提示及相关电梯门控制逻辑。
- **安全保护机制**：包含超时保护、超载检测、紧急停止等功能。

## 技术实现

### SCL 程序设计

项目采用 SCL（Structured Control Language）编写控制逻辑。SCL 是符合 IEC 61131-3 标准的结构化文本编程语言，支持 `IF-THEN-ELSE`、`CASE`、`FOR`、`WHILE` 等语句，适合实现电梯调度、目标队列管理等逻辑。

使用 SCL 有助于将复杂控制流程清晰地组织为结构化程序，便于后续阅读、调试与维护。

### 电梯群控调度策略

项目的群控调度综合考虑以下因素：

1. **等待时间优先**：优先考虑缩短乘客候梯时间。
2. **运行方向匹配**：结合电梯当前运行方向和呼叫需求进行调度。
3. **负载均衡分配**：合理分配各电梯的响应任务。

通过上述策略，协调多部电梯响应楼层请求，兼顾调度效率与运行能耗。

## 项目使用方法

1. 安装 **TIA Portal V18**。
2. 进入 `2023决赛程序` 文件夹，在博途中打开 `2023.ap18`。
3. 检查并配置硬件组态，确认 I/O 地址与实际接线一致。
4. 编译项目，检查并处理编译错误与警告。
5. 将程序下载至对应的 PLC。
6. 运行并调试程序，验证电梯群控及各项控制逻辑。
